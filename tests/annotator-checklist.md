# 批注系统验收清单（annotator.ts + AnnotationToolbar）

> 核心实现：CSS Custom Highlight API（`CSS.highlights` + `::highlight(mk-*)`）。
> 正文 DOM 不插任何包裹节点；线条由浏览器按 Range 真实文字矩形绘制。
> 运行：`npm start` → <http://127.0.0.1:43999>（建议 Chrome/Edge 105+ / Safari 17.2+ / Firefox 140+）。

## 手工逐项验证（浏览器内）

1. **黄色马克笔**：选一个中文短语 → 点马克笔 → 抬笔出现半透明底色，长度=短语宽度；底色后端再选黄点再落，同段可落多处、互不覆盖
2. **蓝波浪**：选一小段 → 色点选蓝 → 点波浪线 → 底下出现细波浪，起止与首末字对齐
3. **绿波浪**：另选一段 → 色点选绿 → 波浪线 → 绿波浪，与蓝波相隔明显
4. **红直线**：选一处 → 点直线 → 红细实线贴字底
5. **长度匹配**：任选一处拖选跨行文字 → 长度仍逐行贴合文字（不允许出现通篇整行的线）
6. **多批注共存**：同一段落连续落 2–3 条不同样式 → 各自独立、无遮挡
7. **删一条不影响别条**：点某条线 → 删除划线 → 只有它消失；⌘Z 恢复
8. **刷新恢复**：划好后刷新页面 → 批注原样回来（服务在线走 `_duiye/annotations`；离线时走 `localStorage[duiye:ann:<id>]` 镜像）
9. **滚动跟随**：选中文字出工具条后滚动页面 → 工具条跟着选区走、不遮主文字；缩放窗口同理
10. **正文不变**：DevTools 里确认正文段落没有新增 span/wrapper；字号、行距、段落结构与批注前一致

## 特殊情形

- [ ] 选中跨 `<em>`/`<strong>`/KaTeX 的文字（多个 text node）→ 能落笔、能恢复
- [ ] 同一段里两次选中同一短语 → 前一条 n=0、后一条 n=1，刷新后各自复位（前后文 `ac` 圈定）
- [ ] 选区跨界到面板/页眉 → 工具条不出
- [ ] Esc 关工具条；点正文空白收工具条；点工具条本身选区不丢
- [ ] 不支持的浏览器（如 Firefox <140）→ 打开文章 toast「不支持批注高亮 API」，无控制台报错，想法/面板照常
